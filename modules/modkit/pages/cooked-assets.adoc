= Cooked Assets

Supported PAYDAY 3 cooked assets can be exposed in the custom editor from the user's installed copy of the game.

They are reference/dependency content, not mod-owned source assets.

[WARNING]
====
Do not redistribute PAYDAY 3 base-game cooked assets with the modkit or your mod.
====

== Why expose cooked content?

Seeing compatible cooked content in the editor allows tooling and mod content to resolve game references without requiring the community modkit to ship the original game data.

== Read-only workflow

Treat base-game cooked content as read-only.

Create mod-owned assets inside your mod. When an asset replacement is required, follow the replacement workflow rather than editing the installed cooked package in place.

== Not every system is reconstructible

Visibility in the Content Browser does not mean every game system can be regenerated by the editor.

Some features depend on native build/generation steps that are not yet reproduced. Those limitations are documented per system.
