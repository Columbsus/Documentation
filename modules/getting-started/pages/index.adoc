= Getting Started
:description: A linear beginner guide to setting up the PAYDAY 3 modkit and creating a first mod.

This guide walks through the complete beginner workflow for PAYDAY 3 modding.

Follow the pages in order the first time through.

== What you will do

By the end of the guide, you will understand the toolchain, open the PAYDAY 3 modding project, create a mod with CrimeForge, package it, and test it with PAYDAY 3.

You do not need to understand PAYDAY 3 reverse engineering or Unreal Engine internals before starting.
