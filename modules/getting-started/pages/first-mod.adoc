== Set up the plugin with CrimeForge

CrimeForge creates the Unreal plugin structure for your mod. Each mod has its own content root, metadata, and files to send through the Forge pipeline.

=== Open Create Mod

Open CrimeForge and click *Create Mod* to open the *New Mod* window.

image::crimeforge:crimeforge-new-mod-window.png[CrimeForge New Mod window, width=1000]

=== Choose the template and name

. Select the *Blank* template for this example.
. Enter `MyFirstMod` in *Mod Name*.
. Fill in the *Author* and *Description* fields.
. Use the normal development location, `<ModkitRoot>/Mods/`, where CrimeForge creates mod plugins.

[CAUTION]
====
Keep the plugin name stable once you start creating referenced assets. The name becomes part of its mount point and asset paths; renaming it later can break references.
====
