= Requirements

Before installing the modkit, prepare the following.

== Required

* A legitimate installed copy of PAYDAY 3.
* The custom PAYDAY 3 Unreal Engine {pd3-engine-version} editor build used by the modkit.
* The PAYDAY 3 modkit project.
* https://fmodel.app/[FModel] for browsing the installed game archives and extracting setup data.

== Development tools

If you will compile the editor, project, plugins, or native modules, install a compatible Visual Studio C++ toolchain.

Blueprint-only mod authors may not need to work directly with C++, but the distributed modkit/editor build must still contain the required compiled modules.


== Before continuing

Launch PAYDAY 3 normally at least once and make sure the base game installation works.

Then continue to xref:install-editor.adoc[Install the Custom Editor]. FModel is configured immediately afterwards in xref:fmodel-setup.adoc[Set Up FModel].
