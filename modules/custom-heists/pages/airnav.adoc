= AirNav

AirNav is a specialist area of custom-heist tooling that is not yet fully supported.

Part of the octree-generation behavior can currently be reproduced, but the AirNavConnector integration cannot yet be generated as an editor workflow.

This affects systems that depend on AirNav, such as Overkill weapon delivery.

[WARNING]
====
Overkill weapon support is not yet complete. It requires the AirNav generation and integration path, which has not been validated end to end.
====
