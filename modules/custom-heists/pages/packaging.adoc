= Forge & Testing

Custom heists use the same CrimeForge Forge pipeline as other CrimeForge mods.

Forge cooks and packages the assets that belong to the heist mod, producing a plugin-based mod that PDML can load.

Install the complete forged heist mod under:

[source,text]
----
PAYDAY3/Mods/
----

Then launch PAYDAY 3 through the normal PDML runtime setup and test the heist in-game.

Additional heist-specific validation and packaging details will be documented as those workflows are finalized.
