= CrimeForge

CrimeForge is the PAYDAY-specific editor tooling layer.

It provides mod creation templates, validation, forging, and specialized authoring workflows.

CrimeForge creates mods as Unreal plugins. This keeps each mod in its own content namespace and gives PDML a predictable structure to discover and load at runtime.

CrimeForge uses the term *Forge* for its cook/package step. Forge cooks the assets selected for the mod and packages only the content that mod should ship with.

image::crimeforge-dashboard.png[CrimeForge mod manager, width=900]

== The CrimeForge mod manager

The main CrimeForge panel gives you a card for each mod.

Each card exposes the most common actions:

* *Information* opens the mod's descriptor and metadata.
* *CONFIG* opens mod-specific configuration.
* *FORGE* runs the cook/package step for that mod.

The panel also includes tools such as *Create Mod*, *Import Legacy Mod*, and selection helpers.
